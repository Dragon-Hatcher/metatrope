# Wordbank

Starting points, not a ledger. **Nothing here is verified** — every gloss below
is a lead to check against a dictionary, not a fact to copy. And this file does
not record what has been used: `puzzles/*.json` is the only authority on that.

Add to it as you read. Words marked ⚠ carry a known problem worth resolving
before you spend effort on them.

## Greek source → Latin target

Numerous and reliable; the risk is monotony, not scarcity. Vary the semantic
field — do not ship a week of animals.

**Creatures** — rhinoceros (nose + horn), chameleon (ground + lion),
pterodactyl (wing + finger), octopus (eight + foot), protozoa (first + animal),
hippodrome (horse + course), dinothere (terrible + beast)

**Instruments** — microscope (small + look), telescope, periscope, stethoscope
(chest + look), thermometer (heat + measure), barometer (weight + measure),
phonograph (sound + write), kaleidoscope (beautiful-form + look)

**Ideas** — democracy (people + power), oligarchy (few + rule), misanthrope
(hate + human), philanthropy (love + human), orthodoxy (straight + opinion),
palindrome (again + running), hierarchy (sacred + rule), metropolis (mother +
city), necropolis (dead + city), encyclopedia ⚠ three roots

**Things** — chrysanthemum (gold + flower), rhododendron (rose + tree),
anthology (flower + gathering), monolith (single + stone), megaphone (great +
sound), hemisphere (half + sphere), pentagon (five + angle)

## Latin source → Greek target

The thin spot is rule 3: Greek synonyms often have only one English descendant.
Check descendants before committing.

**Diet and habit** — omnivore, herbivore, insectivore, somnambulist ✓ used,
noctambulant (night + walk)

**Number and body** — centipede (hundred + foot) ⚠ Greek *hekaton* is thin,
millipede, quadruped, biped, equidistant

**Sky and time** — solstice (sun + standing-still), equinox (equal + night),
matutinal ⚠ single root

**Doing** — manuscript (hand + write), manufacture (hand + make), aqueduct
(water + lead), agriculture (field + cultivate), circumnavigate (around +
sail), benefactor (well + do), magnanimous (great + spirit), omnipotent (all +
power)

**The -cide family** — regicide, fratricide, insecticide (Greek *-ktonos*, as in
*ktonos*/*-tonous*) ⚠ verify the Greek combining form has English reflexes

## Japanese source → Latin or Greek target

The strongest vein: the English words are opaque, so the seam is a genuine
surprise. Give the source root in kana or kanji as well as romaji.

karate (empty + hand), judo (gentle + way), shiatsu (finger + pressure),
hibachi (fire + bowl), bonsai (tray + planting), sensei (before + born),
tycoon (great + lord), honcho (squad + chief), geisha (art + person),
manga (whimsical + picture), umami (delicious + taste), karoshi (overwork +
death), sudoku (number + single), teriyaki (gloss + grill),
kamikaze (god + wind) — already a candidate

⚠ karaoke — the *oke* is clipped from English *orchestra*, so one root is
Germanic-by-way-of-Greek. Fails rule 1.
⚠ rickshaw, aikido — three roots.

## Other sources

Fewer opportunities each, but they make a week feel wider.

**Malay** — orangutan (person + forest). Well attested and delightful.

**Hawaiian** — ukulele (flea + jumping)

**Persian** — paradise (around + wall), pyjamas (leg + garment)

**Sanskrit** — maharaja (great + king), juggernaut (world + lord), ayurveda
(life + knowledge), avatar (down + cross over) ⚠ the Greek calque *katabasis* is
itself an English word — fails rule 4

**Russian** — sputnik (co- + way)

**Chinese** — kowtow (knock + head) ⚠ typhoon: the Chinese and Greek
derivations are both argued, so it fails rule 8

**Nahuatl** — axolotl (water + servant) ⚠ the second root is disputed;
chocolate ⚠ the whole split is disputed

**Arabic** — poor hunting. Most loans are a single root or *al-* plus a root,
which is one lexical root, not two.

## Known dead ends

Keep these on file so they are not rediscovered every batch.

| Word | Why not |
| --- | --- |
| carnivore → *sarkophagos* | clue reads as *sarcophagus* (rule 4) |
| chronometer → *temporimensura* | chronograph, chronoscope and horologe fit equally (rule 5) |
| philosophy → *amorsapientia* | thirteen letters, reads as a phrase (rule 6) |
| centipede → *hekatopous* | *hekaton* has only *hecatomb* in English (rule 3) |
| television, bicycle | Greek and Latin in one word — no single source language (rule 1) |
| lucifer → *phosphoros* | *phosphorus* is an English word (rule 4) |
